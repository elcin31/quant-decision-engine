# Quant Decision Engine — UI System

## Product character
Minimal, precise, technical, premium, research-oriented.

The interface is deliberately closer to a quantitative research terminal and scientific instrument than a conventional SaaS dashboard.

## Visual rules
- Near-black base with restrained elevated surfaces.
- Lime accent used for actions, active state, and key positive signals.
- Thin borders and dense information hierarchy.
- Manrope for interface text, DM Mono for numeric/technical data.
- No gradients, glassmorphism, oversized cards, decorative illustrations, or AI-chat styling.
- Data takes visual priority over decoration.

## Information architecture
- Research: method library and quick-start analyses.
- New Analysis: method selection, inputs, execution, results.
- Analysis workspace: configuration on the left/above and result surface below.
- Results are metric-first, then visualization, then context.

## Mobile
The mobile layout is not a shrunken desktop layout:
- compact sticky header
- two-column method grid
- hidden desktop research sidebar
- single-column forms
- sticky analysis action row
- horizontally scrollable technical tables/charts where necessary

## Product language
Use research terminology:
- Analysis
- Method
- Observations
- Confidence
- Annualization
- Simulation
- Distribution
- Scenario
- Benchmark

Avoid:
- AI magic
- Buy/Sell
- Portfolio health scores
- generic dashboard language

## Workflow
Research → Calculate → Simulate → Understand → Decide

The final stage is decision support, not an autonomous investment recommendation.
